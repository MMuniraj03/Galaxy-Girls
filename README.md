# Galaxy Girls — Professional Game Build

This build uses the updated PNG/JPEG assets supplied with the project.

## Updated gameplay rules

- Heroine maximum health: **350 HP**
- Starting lives: **5**
- Normal enemy contact damage: **50 HP**
- Boss contact damage: **100 HP**
- Boss projectile damage: **150 HP**
- Enemy Level 1: **100 HP**
- Enemy Level 2: **150 HP**
- Enemy Level 3: **200 HP**
- Boss Level 1: **500 HP**
- Boss Level 2: **750 HP**
- Boss Level 3: **1000 HP**
- Gun 1: **50 damage**
- Gun 2: **75 damage**
- Gun 3: **100 damage**
- Gun 4: **125 damage**
- Health loot: **+30% of max health (+105 HP), capped at 350**
- Gun loot: **+1 gun level**
- Life loot: **+1 life**
- Enemy levels 1/2/3 are mixed during normal gameplay.
- Every enemy displays current/max HP above its head.
- Bosses also display their HP.
- Normal enemies **do not shoot**.
- Bosses shoot **slowly**.
- Boss 1 starts at **25 enemy kills** (2500% interpreted as 25 enemies).
- Boss 2 starts at **50 enemy kills**.
- Boss 3 starts at **100 enemy kills**.
- Gun art changes in the heroine's hand when the gun level changes.
- After Boss 3 is defeated, the mission-complete screen appears.

## Files

- `index.html` — page structure
- `game.css` — visual styling and responsive mobile layout
- `game.js` — game engine, progression, combat, loot, bosses and controls
- Asset PNG/JPEG files — supplied game artwork

## GitHub

Keep all three code files and all asset files in the same folder if you want to use the paths exactly as written.

Open `index.html` in a browser, or enable GitHub Pages for the repository to publish it.
